# Generated bindings (HEL-002)

Generated Go and Python code from `proto/` belongs here after you run the codegen script.

Suggested layout (you may adjust):

```text
gen/go/helios/inference/v1/   # Go package from protoc
gen/python/helios/inference/v1/  # Python *_pb2.py / *_pb2_grpc.py
```

Commit generated files once you choose a generate-and-commit workflow in HEL-002. Do not edit generated files by hand.
